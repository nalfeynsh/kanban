# Тайный Санта — документация модуля

Статус: **MVP реализован**, миграция `037_secret_santa.sql` применена к БД. Флаг `secret_santa` выключен до деплоя новой версии приложения.

## Документы

- [Техническое задание](tz.md) — сценарии, роли, модель данных, RLS, жеребьёвка, бюджет, оценка.

## Реализация

Код модуля: `src/features/secret-santa/`.

- `SecretSantaModal.jsx` — контейнер: список игр, создание, открытие;
- `SecretSantaGame.jsx` — игра, участники, пожелания, жеребьёвка, своя пара;
- `SecretSantaCreateForm.jsx` — создание и редактирование, бюджет «от/до»;
- `api.js` — RPC и запросы;
- `utils.js` — форматирование дат и бюджета.

Миграция: `supabase/migrations/037_secret_santa.sql`.  
Полное удаление: `supabase/migrations/037_secret_santa_rollback.sql`.

## Границы

Документация модуля хранится отдельно от основного ТЗ:

```text
docs/modules/secret-santa/
src/features/secret-santa/     — появится при реализации
```

Правила:

1. Всё, что относится только к «Тайному Санте», лежит в этой папке.
2. Основной `AGENTS.md` содержит только ссылку на модуль, без деталей.
3. Код модуля не хранится в `docs/`; документация не импортируется приложением.
4. Изображения и макеты — в `assets/`.
5. После удаления модуля папка документации удаляется вместе с кодом и миграцией.

## Текущее решение

- модуль отдельный, с префиксом таблиц `secret_santa_`;
- включается флагом `secret_santa`;
- бюджет задаётся диапазоном «от/до»;
- жеребьёвка выполняется на сервере;
- организатор не видит пары;
- удаление не затрагивает задачи, колонки, профили и проекты.
