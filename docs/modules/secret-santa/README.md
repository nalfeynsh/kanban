## Границы

Документация модуля хранится отдельно от основного ТЗ:

```text
docs/modules/secret-santa/
src/features/secret-santa/     — появится при реализации
```

Правила:

1. Всё, что относится только к «Тайному Санте», лежит в этой папке.
2. Основной `AGENTS.md` содержит только ссылку на модуль, без деталей.
3. Код модуля не хранится в `docs/`; документация не импортируется приложением.
4. Изображения и макеты — в `assets/`.
5. После удаления модуля папка документации удаляется вместе с кодом и миграцией.

## Текущее решение

- модуль отдельный, с префиксом таблиц `secret_santa_`;
- включается флагом `secret_santa`;
- бюджет задаётся диапазоном «от/до»;
- жеребьёвка выполняется на сервере;
- организатор не видит пары;
- удаление не затрагивает задачи, колонки, профили и проекты.
