# Безопасность «Мой Канбан»: публичное описание

**Черновик для страницы Trust/Security. Не является гарантией SLA.**

## Архитектура

- React-клиент, сервер Layero, Supabase (Postgres, Auth, Storage, Realtime).
- Доступ к данным — через Supabase с RLS-политиками.
- Файлы и аватары — в приватных bucket с политиками доступа.
- Роли: администратор, руководитель, заместитель, сотрудник, пользовательские роли.

## Защита данных

- HTTPS для передачи данных.
- Разграничение доступа на уровне базы (RLS) и приложения.
- Приглашения вместо открытой регистрации.
- Приватные задачи видны только автору.
- Пароли обрабатываются Supabase Auth; приложение не хранит пароли.
- Сессии — в локальном хранилище браузера.
- Журналирование ошибок и действий, резервное копирование.

## Что не используется

- Нет продажи данных.
- Нет сторонних рекламных трекеров и аналитических cookie на текущем этапе.
- Нет биометрической идентификации.
- Нет записи встреч по умолчанию.

## Ограничения

- База и резервные копии находятся в Supabase Cloud, регион eu-west-1 (Ирландия),
  вне РФ. Это ограничение нужно устранить до коммерческой эксплуатации.
- Пилотный режим не гарантирует SLA и непрерывность.
- Запись встреч, если включена, требует согласия участников.
